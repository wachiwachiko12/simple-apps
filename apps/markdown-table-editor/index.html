  1. セルをクリックして直接テキストを入力します。
    2. 
        
  2. Tab キーで右のセルへ、Shift+Tab で左のセルへ移動します。
    3. 
        
  3. Enter キーで下のセルへ、矢印キー（↑↓←→）でも移動できます。
    4. 
        
  4. 「行を追加 / 削除」「列を追加 / 削除」ボタンでテーブルの大きさを調整します。
    5.

    7. 
        
  7. 既存のMarkdownテーブルを「読み込む」フォームに貼り付けて「テーブルに読み込む」をクリックすると、GUIで編集できます。
    8. 
        
  8. 入力内容はブラウザの localStorage に自動保存されるため、ページを閉じても次回開いたときに続きから編集できます。

このツールについて

      

        Markdownテーブル作成ツールは、GitHubのREADMEやQiita・Zennの記事、Notionドキュメントなどで使われるMarkdown形式のテーブルを、Excelライクな直感的GUIで作成・編集できる完全無料のブラウザツールです。従来はテキストエディタで | と - を手打ちする必要がありましたが、このツールならセルをクリックして文字を入力するだけでMarkdownコードが自動生成されます。Mac専用有料アプリ「TableFlip」の完全無料代替として、OS・ブラウザを問わず利用できます。生成したMarkdownはワンクリックでコピーでき、開発ドキュメントや技術ブログの執筆効率を大幅に向上させます。アカウント登録不要、サーバーへのデータ送信なし、データはすべてお使いのブラウザ内に保存されます。
      


      
よくある質問

      

        
入力したテーブルのデータはどこに保存されますか？

        
入力内容はブラウザのlocalStorageに自動保存され、次回アクセス時も編集途中のテーブルが復元されます。サーバーへの送信は行われないため社外秘の資料でも安心してご利用いただけますが、ブラウザのキャッシュを削除すると内容は失われます。

        
行数・列数に上限はありますか？

        
アプリ側での明確な上限は設けていませんが、行・列を増やしすぎるとスマートフォンでは横スクロールが必要になり操作しづらくなります。GitHub READMEやドキュメント用途では10列・数十行程度までが実用的な目安です。

        
既存のMarkdownテーブルを読み込むとき、対応していない形式はありますか？

        
1行目をヘッダー、2行目を「|---|---|」形式の区切り線とする標準的なMarkdownテーブル記法に対応しています。セル内に改行を含む表や、パイプ文字「|」をエスケープせずに使っている表は正しく読み込めない場合があります。

        
セル内に改行やパイプ「|」を入力できますか？

        
セルは1行のテキスト入力欄のため改行はサポートしていません。パイプ文字「|」を含めるとMarkdownのテーブル区切りと衝突し正しく表示されない場合があるため、記号「/」など別の表現に置き換えることをおすすめします。

        
コピーしたMarkdownが崩れて見える場合は？

        
生成されるMarkdownは列ごとの最大文字幅に合わせて等幅にパディングしていますが、全角文字と半角文字で表示幅が異なるため、貼り付け先のエディタによっては列がずれて見えることがあります。表示自体は多くのMarkdownパーサーで正しくレンダリングされます。
