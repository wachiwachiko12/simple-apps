コードスニペット画像化ツール

コードをPNG画像に変換 — Zenn・Qiita・SNS投稿に最適

プレビュー

関連ツール： Gitコミットメッセージフォーマッター Webパフォーマンス予算ツール

使い方

  1. 下のテキストエリアにコードを貼り付けます。
  2. 言語・テーマ・背景色・フォントサイズを設定します。
  3. 右側のプレビューでリアルタイムに確認します。
  4. 「PNG画像でダウンロード」ボタンを押して画像を保存します。
  5. 保存した画像をZenn・Qiita・X（Twitter）に投稿します。

コードスニペット画像化ツールとは

コードスニペット画像化ツールは、プログラムのソースコードを美しいPNG画像に変換できるWebサービスです。 エンジニアや技術ブロガーがZenn・Qiita・X（旧Twitter）・note などのSNSにコードを投稿する際、 コードブロックが使えないプラットフォームでも画像として共有できるようになります。 Carbon（carbon.now.sh）の日本語フォント対応版として、日本語コメントや日本語変数名も正しく表示されます。 シンタックスハイライトにはHighlight.jsを使用し、JavaScriptやPython・Go・Rustなど12言語に対応。 macOS風のウィンドウボタン（赤・黄・緑のドット）でリアルなエディタ風の見た目を演出できます。 登録不要・完全無料でブラウザだけで動作します。

対応テーマ一覧

  • Dark（デフォルト） — 定番のダークテーマ。目に優しく視認性が高い。
  • Light — 明るい背景のライトテーマ。印刷にも適している。
  • Dracula — 人気のDraculaカラーパレット。紫・ピンク系の配色。
  • One Dark — Atom/VS Code ユーザーにおなじみの落ち着いた暗色テーマ。
  • Solarized Dark — 目に優しい低コントラストの定番テーマ。

よくある質問

入力したコードはサーバーに送信されますか？
いいえ。コードのハイライト表示にはHighlight.js、画像化にはhtml2canvasを使用しており、いずれもブラウザ内で完結する処理です。入力したコードが外部サーバーに送信されることはありません。
ダウンロードされる画像の解像度はどのくらいですか？
html2canvasのscaleオプションを2倍（2x）に設定して生成しているため、Retinaディスプレイでもくっきり表示できる高解像度のPNG画像がダウンロードされます。
対応しているプログラミング言語は何ですか？
JavaScript・TypeScript・Python・Go・Rust・Java・HTML・CSS・Shell/Bash・SQL・JSONの主要11言語と、その他汎用テキスト表示に対応しています。シンタックスハイライトはHighlight.jsのハイライトルールに基づいて表示されます。
コードが長い場合、画像が見切れることはありますか？
長いコード・長い行はコードカード内でそのままレイアウトされるため、非常に長いコードの場合は画像の縦横サイズが大きくなります。SNS投稿には数行〜数十行程度の短いコードスニペットでの利用がおすすめです。

参照情報・免責事項

シンタックスハイライトにはHighlight.js、画像生成にはhtml2canvasを利用しています。入力したコードはブラウザ内で処理され、サーバーには送信されません。

免責事項：入力するコードの著作権・機密情報の取り扱いはご利用者様の責任で管理してください。生成した画像をSNS等で公開する前に、APIキーやパスワードなど機密情報が含まれていないか必ずご確認ください。
