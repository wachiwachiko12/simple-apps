関連ツール： フリーランス確定申告シミュレーター 副業手取りシミュレーター 請求書ジェネレーター

使い方

  1. 画面上部のタブ（Q1〜Q4）から管理したい四半期を選択します。
  2. 「+ Objectiveを追加」ボタンで目標（Objective）を最大4つ作成します。
  3. 各ObjectiveカードのKey Result（成果指標）欄に、目標値・現在値・単位を入力します。
  4. 達成率が自動計算され、カラーバーとサマリーに反映されます。
  5. データはブラウザのlocalStorageに自動保存されます。ページを閉じても保持されます。

OKRとは

OKR（Objectives and Key Results）は、Google・Intelなどが採用する目標管理フレームワークです。「Objective（何を達成するか）」と「Key Result（達成をどう測定するか）」をセットで設定することで、曖昧な目標を定量化し、進捗を可視化できます。個人・フリーランスが四半期単位で使うことで、売上目標・スキルアップ・案件獲得などの優先事項を整理し、集中して行動できる効果があります。従来はResily・Wistantなどの有料ツールが主流でしたが、このツールは登録不要・完全無料でお使いいただけます。

進捗バーの見方

  • 赤（0〜40%）: 未達・要注意。アクションの見直しが必要です。
  • 黄（41〜70%）: 進行中。このまま継続するか戦略を調整しましょう。
  • 緑（71〜100%）: 順調。目標達成に向けて良いペースです。

フリーランス向けOKR設定例

  • Objective: 収入目標を達成する — KR: 月次売上100万円 / 新規クライアント3件獲得
  • Objective: スキルアップを実現する — KR: 資格1つ取得 / 技術記事10本執筆
  • Objective: 案件獲得率を上げる — KR: 提案数20件 / 成約率30%達成

よくある質問

Objective（目標）はいくつまで作成できますか？
1つの四半期につき最大4つのObjectiveを作成できます。各Objectiveには最大5つのKey Result（成果指標）を設定可能です。上限に達すると「+ Objectiveを追加」ボタンが無効化されます。
達成率はどのように計算されますか？
各Key Resultの達成率は「現在値 ÷ 目標値 × 100」で計算され（100%が上限）、Objectiveの達成率はそのObjective内の入力済みKey Resultの達成率の平均値です。名称未入力のKey Resultは計算対象から除外されます。
データはどこに保存されますか？年をまたいでQ1のデータは分かれますか？
データはブラウザのlocalStorageに自動保存されます。ただし現在の実装ではQ1〜Q4はタブ単位で保存されており、年ごとの区別はありません。翌年に同じQ1タブでデータを入力すると前年のデータは上書きされるため、年をまたいで記録を残したい場合は期末にスクリーンショット等で記録を残すことをおすすめします。
目標値・現在値の単位（%・件・円など）は自由に設定できますか？
はい。「単位」欄はテキスト入力のため、%・件・万円・本など任意の単位を入力できます。達成率の計算は現在値と目標値の比率のみで行われ、単位は表示用のラベルとして扱われます。
進捗バーの色（赤・黄・緑）の基準は？
達成率0〜40%は赤（未達・要注意）、41〜70%は黄（進行中）、71〜100%は緑（順調）で表示されます。この基準はOKRフレームワークで一般的に使われる目安を採用しています。
