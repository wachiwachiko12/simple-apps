使い方

  1. 変換したい方向のタブ（西暦→和暦、和暦→西暦、年齢計算）を選択します。
  2. 年号または西暦を入力して「変換する」ボタンを押します。
  3. 変換結果が即座に表示されます。干支は「年齢早見表」タブの一覧で確認できます。

対応元号：明治（1868年〜）・大正（1912年〜）・昭和（1926年〜）・平成（1989年〜）・令和（2019年〜）。西暦1868年以降の全年に対応。生まれた元号と年を入力すると今年（年）時点の満年齢も計算できます。

年齢・干支の計算について

年齢は「今年の西暦 − 生まれた年の西暦」で算出しています。これは年の差であり、誕生日を迎えているかどうかで実際の満年齢は±1歳変わります。干支は十二支のサイクル（西暦を12で割った余り）で算出しており、12年ごとに同じ干支が巡ってきます。たとえば2026年は午（うま）年で、12年前の2014年も同じ午年です。干支は「年齢早見表」タブの一覧に表示されます。

よくある質問（FAQ）
昭和64年と平成元年は同じ日付ですか？
昭和64年は1989年1月1日〜1月7日の7日間のみ存在します。1989年1月8日からは平成元年となり、同じ西暦の年に2つの元号が存在します。
令和は何年から始まりましたか？
令和は2019年5月1日に始まりました。令和元年＝2019年、令和2年＝2020年です。令和7年は2025年、令和8年は2026年になります。
旧暦（和暦）と西暦の違いは何ですか？
本ツールが扱う「和暦」は元号を使った日本独自の年号制度（グレゴリオ暦ベース）です。「旧暦」（太陰太陽暦）とは異なり、月日の計算は旧暦ではなく新暦（西暦）と同じです。
昭和生まれは2026年時点で何歳ですか？
昭和元年（1926年）生まれが100歳、昭和64年（1989年）生まれが37歳です。詳しくは「年齢早見表」タブをご確認ください。
平成生まれは2026年時点で何歳ですか？
平成元年（1989年）生まれが37歳、平成31年（2019年）生まれが7歳です（いずれも誕生日前後±1歳）。
大正生まれは現在も生存しますか？
大正は1912年〜1926年です。2026年時点で大正生まれは100〜114歳になります。100歳以上の方が対象です。
西暦1868年より前の年は変換できますか？
本ツールは明治元年（1868年）以降に対応しています。それ以前は江戸時代の元号となり、現在の法令上の元号制度の範囲外のため対応外としています。
参照情報・免責事項
  • 内閣府：元号に関する情報
  • 法務省：改元に関する情報

本ツールの元号定義は内閣府告示および政令に基づいています。令和（2019年5月1日〜）、平成（1989年1月8日〜2019年4月30日）、昭和（1926年12月25日〜1989年1月7日）、大正（1912年7月30日〜1926年12月24日）、明治（1868年1月25日〜1912年7月29日）。

免責事項：本ツールの変換結果は参考値です。公的書類への記入や法的手続きには、必ず公式情報をご確認ください。

書類記入でつまずく4つのケース

和暦と西暦の変換が必要になるのは、たいてい何かの書類を書いている最中です。ここでは実際につまずきやすい場面を取り上げ、このツールでどう確認すればよいかを具体的に説明します。

ケース1：履歴書に「昭和60年4月生まれ」を西暦で書く

場面：履歴書は西暦で統一したいが、免許証や戸籍の記載は和暦になっている

「和暦 → 西暦」タブで元号に昭和、年に60を入力すると、西暦1985年と表示されます。履歴書の生年月日欄には「1985年4月」と記入します。

年齢を書く欄がある場合は注意が必要です。2026年から1985年を引くと41ですが、これは年の差であって満年齢ではありません。4月生まれの方であれば、4月の誕生日を迎えた後なら41歳、それより前の1月〜3月の時点ではまだ40歳です。履歴書の年齢は提出日または記入日時点の満年齢を書くのが通例なので、誕生日を過ぎているかどうかを必ず確認してください。

また、学歴欄の入学・卒業年を計算する際にも同じ変換が使えます。日本の学校は4月始まりなので、1985年4月生まれの方は1991年4月に小学校へ入学し、以降6年・3年・3年と積み上げる形になります。早生まれ（1月〜3月生まれ）の場合は学年が1つ上になる点に注意してください。

ケース2：「昭和64年」と「平成元年」が同じ1989年になる

場面：親族の書類に「昭和64年1月」とあるが、別の書類では「平成元年」と書かれている

「西暦 → 和暦」タブに1989と入力すると、結果は「平成元年 または 昭和64年」と2つ表示され、「改元をまたいでいるため複数の和暦が存在します」という注記が出ます。これは入力ミスでも不具合でもありません。

昭和は1989年1月7日で終わり、平成は1989年1月8日から始まりました。つまり昭和64年は1月1日から1月7日までのわずか7日間しか存在しません。1989年1月5日生まれの方は昭和64年生まれ、1月10日生まれの方は平成元年生まれとなり、同じ月に生まれていても和暦の表記が変わります。書類が食い違って見えるときは、年だけでなく日付まで見て判断する必要があります。どちらの表記も正しいので、書類を作り直す必要はありません。

ケース3：車検証・保険証券の「平成31年」を西暦に直す

場面：契約書類が和暦表記で、更新期限を西暦のカレンダーアプリに入れたい

平成31年は西暦2019年です。ただし平成は2019年4月30日で終わり、5月1日から令和元年になりました。平成31年として存在するのは1月1日から4月30日までの4か月間だけです。したがって「平成31年5月」以降の日付が書かれた書類があれば、それは記載誤りか、改元前に作成されて西暦換算がずれている可能性があります。

逆に「令和元年」は2019年5月1日から12月31日までを指します。2019年の書類は前半と後半で元号が変わるため、契約日・満了日を扱うときは特に注意してください。

ケース4：いま作る書類に「令和何年」と書くか

場面：申請書の日付欄が「令和　　年　　月　　日」の形式になっている

このツールはページを開いた時点で当年の変換を自動実行しているため、何も入力しなくても画面上部に今年の答えが出ています。2026年は令和8年です。申請書の日付欄にはそのまま「令和8年」と記入してください。

年度で書く必要がある書類の場合は、日本の年度が4月始まり翌年3月終わりである点に注意します。2026年1月〜3月は「令和7年度」、2026年4月以降が「令和8年度」となり、暦年の元号表記とはずれます。

換算のしくみと、暗算でできる覚え方

本ツールの変換は単純な足し算・引き算で成り立っています。式は「西暦 ＝ 元号の開始年 ＋ 和暦の年 − 1」です。元年（1年目）が開始年そのものにあたるため、1を引く必要があります。この式を組み替えると、元号ごとに固定の数を足すだけで換算できるようになります。

元号和暦→西暦西暦→和暦検算例
令和+ 2018− 2018令和8年 + 2018 = 2026年
平成+ 1988− 1988平成31年 + 1988 = 2019年
昭和+ 1925− 1925昭和64年 + 1925 = 1989年
大正+ 1911− 1911大正15年 + 1911 = 1926年
明治+ 1867− 1867明治45年 + 1867 = 1912年

昭和の「+25（下2桁）」は特に覚えやすく、昭和40年＝1965年、昭和50年＝1975年のように下2桁の足し算だけで済みます。令和は「−18」と覚えるとさらに簡単で、西暦の下2桁から18を引けば令和の年になります（2026 − 18 = 8）。ただしこの暗算はいずれも改元の月日をまたぐと成立しません。1912年・1926年・1989年・2019年の4つの年だけは元号が切り替わるため、必ず日付まで確認してください。

干支も同じく計算で求まります。十二支は12年周期なので、西暦を12で割った余りで決まります。2026年は午（うま）年で、12を足し引きした2014年・2038年も午年です。年齢早見表タブでは各年の干支を一覧で確認できます。

ツールの使い分けと実務上のポイント

  1. 1件だけ調べるなら変換タブ、世代でまとめて見るなら早見表タブ。「和暦 → 西暦」「西暦 → 和暦」の各タブは1件ずつの変換に向いています。一方「年齢早見表」タブは明治元年から今年までのすべての年を一覧表示でき、元号ボタンで令和・平成・昭和・大正に絞り込めます。名簿の年齢欄をまとめて埋めるような作業ではこちらが速いです。
  2. ページ下部の「和暦・西暦 早見表」は直近60年分です。2026年から1967年（昭和42年）までを新しい順に並べており、今年の行には★印が付きます。それより古い年を調べたい場合は、年齢早見表タブの元号フィルタをお使いください。
  3. 書類は西暦か和暦のどちらかに統一する。履歴書や職務経歴書で「1985年入学／平成3年卒業」のように混在させると、読み手が毎回換算し直すことになり、印象がよくありません。まず全体をどちらで書くか決めてから、このツールで一括変換するのが効率的です。なお公的書類（年金・登記・税務関係）は和暦の様式が残っているものが多く、指定がある場合は様式に従ってください。
  4. 年齢の記入は「年の差」ではなく「満年齢」で。このツールが表示する年齢および早見表の年齢は、西暦の引き算による年の差です。誕生日を迎える前の時点では、そこから1歳引いた数が満年齢になります。早見表に「※誕生日を迎えているかどうかによって±1歳異なります」と注記しているのはこのためです。

陥りやすい誤解と注意点

  • 元年は「1年」と書かないのが通例です。各元号の最初の年は「令和元年」「平成元年」のように表記します。このツールも年に1を入力すると「令和元年」と元年表記で返します。ただし公的な統計や一部の様式では「令和1年」と書く場合もあるため、書類の指定に従ってください。
  • 元年と最終年は、1年に満たないことがあります。昭和元年は1926年12月25日から12月31日までの7日間、昭和64年は1989年1月1日から1月7日までの7日間しかありません。明治元年も1868年1月25日からで、1年に満たない期間です。「昭和元年生まれ」は12月下旬の7日間に生まれた方に限られる、という珍しい状況が生まれます。
  • 和暦は旧暦ではありません。本ツールが扱う和暦は元号による年の数え方であり、月日はグレゴリオ暦（現在のカレンダー）と同じです。太陰太陽暦である旧暦の日付とは異なるため、旧暦の行事日を求める用途には使えません。
  • 対応範囲は明治元年（1868年）から2100年までです。それ以前の慶応・元治といった江戸時代の元号には対応していません。明治より前の年号が必要な場合は、国立国会図書館などの資料をご確認ください。
  • 改元をまたぐ年は2つの答えが正解です。1912年（明治45年／大正元年）、1926年（大正15年／昭和元年）、1989年（昭和64年／平成元年）、2019年（平成31年／令和元年）の4つの年は、どちらの和暦も存在します。この4年については、必ず月日まで確認したうえで書類に記入してください。
